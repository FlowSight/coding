# Invitation matching starter

This full-stack seed contains a Go 1.22/Gin matching API and a React/Vite
compatibility-matrix UI.

In separate terminals:

```bash
(cd backend && go mod download && go run ./cmd/server)
(cd frontend && npm install && npm run dev)
```

Run `cd backend && go test ./internal/core` for the focused baseline. The
augmenting-path reroute bug is intentional. Assignment output and incremental
compatibility updates remain descriptively named follow-up APIs.

# Maximum Accepted Invitations — full-stack starter

Requires Node.js 20+. The Express matching API accepts a compatibility grid;
the React planner edits the grid and shows the maximum accepted count.

Run `cd backend && npm install && npm start`, then
`cd frontend && npm install && npm run dev`.

Core tests are dependency-free: `cd backend && node --test`. The baseline
intentionally has one failing augmenting-path regression. Assignment-returning
and incremental-compatibility APIs remain incomplete.
